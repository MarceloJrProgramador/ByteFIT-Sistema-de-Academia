# 💪-ByteFIT-Sistema-de-Gest-o-para-Academia

📌 Sobre o projeto

O ByteFIT é um sistema desenvolvido em Python com o objetivo de organizar processos de gestão de uma academia, reunindo cadastro de clientes, seleção de planos, serviços adicionais e geração de fichas de treino personalizadas.

Este projeto foi desenvolvido como parte da minha jornada de aprendizado em Análise e Desenvolvimento de Sistemas, aplicando conceitos de lógica de programação e desenvolvimento de software.


🚀 Funcionalidades

Cadastro de clientes: pré-cadastro e registro de informações pessoais e de contato.

Gestão de planos: visualização e seleção de planos Basic, Plus e Premium.

Serviços adicionais: seleção de serviços com cálculo automático do valor mensal.

Cadastro completo: registro de endereço, status e simulação de captura de Face ID.

Fichas de treino: geração de treinos conforme a frequência semanal e os grupos musculares.

Cálculos: estimativa de IMC e necessidades calóricas.

Exportação de fichas: salvamento dos treinos em arquivos .txt.

Validação de dados: verificações para entradas como telefone, peso, altura e idade.

Menus interativos: navegação pelo sistema utilizando o terminal.
